# Odin Recipes

This is a project from The Odin Project's Foundations course. It's a basic recipe website built using plain HTML — no CSS or JavaScript yet.

The site has a main index page linking out to individual recipe pages, each showing an image, description, ingredients, and steps.

## Skills demonstrated
- Structuring a multi-page website with HTML
- Using semantic HTML elements (headings, lists, links, images)
- Organizing a project with relative file paths and folders
- Basic Git/GitHub workflow (commits, push, GitHub Pages)
